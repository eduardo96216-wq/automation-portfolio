# Automated User Onboarding

Automated onboarding workflow built with **Power Automate** and **Microsoft 365**
to streamline user onboarding and reduce manual IT operations.

---

## 📌 Business Problem
Manual onboarding processes are time-consuming and error-prone,
especially when user data is incomplete or inconsistently handled between HR and IT.

---

## ✅ Solution Overview
This workflow automates the onboarding process when a new record is created
in a SharePoint list:

- Initializes variables for user data
- Validates email presence before execution
- Sends a welcome email to the new user
- Notifies IT when required data is missing
- Updates onboarding status for full traceability
